## TAS-RX-900-C3 (جاهز v1.0)

مستقبل 868/915 ميغاهرتز: ESP32-C3 + E28-900M22S (SX1276). متوافق مع الأطراف
مع الهدف `Unified_ESP32C3_900_RX_via_UART` — **صفر تغييرات في البرنامج**.

- `TAS-RX-900-C3/TAS-RX-900-C3.kicad_sch` — المخطط (KiCad 8)
- `TAS-RX-900-C3/TAS-RX-900-C3.kicad_pcb` — هيكل لوحة 25×35 مم (حدود، مواضع
  المكوّنات، منطقة أرضي؛ توجيه يدوي قبل التصنيع!)
- `TAS-RX-900-C3/PINOUT_AR.md` — الخرائط وقواعد تخطيط RF
- `TAS-RX-900-C3/BOM.csv` — قائمة المواد (~12 بنداً)
- `../src/hardware/RX/TAS RX 900 C3.json` — ملف تعريف العتاد يُحمَّل عبر Configurator

## إجراء التشغيل

1. اصنع اللوحة وفق PINOUT (بعد التوجيه اليدوي وفحص DRC!).
2. جمّع حسب BOM؛ وصّل الهوائي قبل أول تشغيل (مرحّد القدرة بدون هوائي يدمر SX1276).
3. البرمجة: Configurator → custom target ← حمّل JSON `TAS RX 900 C3.json` ←
   برنامج `Unified_ESP32C3_900_RX_via_UART` مبني بـ`-DTAS_HARDENING`.
4. اختبار failsafe على الطاولة + اختبار المدى وفق القسم 7 من TAS_README الرئيسي.

## قواعد تصميم العتاد

- كل مكوّن من مصدرين مستقلين على الأقل (الدرس L4).
- الهوائي مثبّت دائماً قبل التشغيل؛ قدرة الإرسال ضمن القانون المحلي.
- كل مراجعة لوحة = مجلد خاص (`TAS-RX-900-C3-revB/`...) ولا تكتب فوقها أبداً.
