# TAS-RX-900-C3 — розпіновка та контракт з прошивкою

Карта пінів має **три джерела істини**, які змінюються разом в одному коміті:
1. цей файл,
2. `src/hardware/RX/TAS RX 900 C3.json`,
3. схему KiCad.

| Функція прошивки | GPIO C3 | Мережа KiCad | Примітки |
|---|---|---|---|
| CRSF UART RX | 20 | UART_RX | до FC |
| CRSF UART TX | 21 | UART_TX | до FC |
| SX1276 SCK | 6 | SPI_SCK | |
| SX1276 MOSI | 7 | SPI_MOSI | |
| SX1276 MISO | 4 | SPI_MISO | |
| SX1276 NSS | 5 | SPI_NSS | |
| SX1276 RST | 2 | RF_RST | |
| SX1276 DIO0 | 3 | RF_DIO0 | RX/TX done |
| SX1276 DIO1 | 10 | RF_DIO1 | CAD/CRC err |
| LED статусу | 8 | — | через R1 1k |
| Кнопка bind | 9 | — | BOOT, внутр. pull-up, кнопка на GND |

## Чому саме ці GPIO
- **18/19 вільні** → нативний USB-C (прошивка/OTA без перехідника).
- **11–17 пропущені** → зарезервовані внутрішнім flash модуля WROOM-02.
- **9 = BOOT**: подвійна роль кнопки bind, як на stock платах C3.
- Потужність: `power_values [120,124,127]` = регістри PA SX1276 ідентичні
  `Generic 900.json` (≤ ~+13 dBm e.i.r.p. з антеною ≤2 dBi — перевірте закон).

## Обов'язкові правила RF-розкладки
1. Мікросмуга ANT_FEED 50 Ω — **3,06 мм** на FR4 1,6 мм εr 4,4 (2 шари). Для 1,0 мм: ~2,2 мм.
2. Найкоротша лінія антени, **без via** у сигнальній лінії.
3. Суцільна земля F.Cu та B.Cu; паркан via кожні ≤ 2,5 мм вздовж лінії антени.
4. Зона антени модуля E28 (край з PCB-антеною): **без міді**, keepout 8×5 мм.
5. LDO: C1 біля VIN, C2 біля VOUT; землю LDO пучком via до GND.
6. Крайова SMA: центральний pad виходить ~1 мм за Edge.Cuts.

## Статус CAD
- Схема: логічно повна (мережі збігаються з JSON вище).
- PCB: **каркас** — контур, footprint-и, GND-зона; **ручне трасування + DRC +
  перевірка другою особою перед замовленням.**
