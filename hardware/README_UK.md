Референсна електроніка для цілей прошивки цього форку.

## TAS-RX-900-C3 (готово v1.0)

Приймач 868/915 МГц: ESP32-C3 + E28-900M22S (SX1276). Сумісний за пінами з
ціллю `Unified_ESP32C3_900_RX_via_UART` — **нуль змін у прошивці**.

- `TAS-RX-900-C3/TAS-RX-900-C3.kicad_sch` — схема (KiCad 8)
- `TAS-RX-900-C3/TAS-RX-900-C3.kicad_pcb` — каркас PCB 25×35 мм (контур, footprint-и, GND-зона; ручне трасування перед виробництвом!)
- `TAS-RX-900-C3/PINOUT.md` — розпіновка та правила RF-розкладки
- `TAS-RX-900-C3/BOM.csv` — перелік компонентів (~12 позицій)
- `../src/hardware/RX/TAS RX 900 C3.json` — hardware-def для прошивання через ELRS Configurator

## Порядок запуску

1. Виготовте PCB за PINOUT.md (після ручного трасування та DRC!).
2. Зберіть за BOM; під'єднайте антену ДО першого увімкнення (PA без антени вбиває SX1276).
3. Прошивка: Configurator → custom target → завантажте JSON `TAS RX 900 C3.json` → прошивка `Unified_ESP32C3_900_RX_via_UART` зі `-DTAS_HARDENING`.
4. Стендовий тест failsafe + тест дальності згідно з розділом 7 головного TAS_README.

## Правила проєктування заліза

- Кожна деталь щонайменше з 2 незалежних джерел (урок L4).
- Антена завжди до увімкнення; потужність у межах місцевого закону.
- Кожна ревізія PCB = окремий каталог (`TAS-RX-900-C3-revB/` тощо), ніколи не перезаписувати.
